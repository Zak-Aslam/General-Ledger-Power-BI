# 2025 General Ledger Review

A Power BI portfolio project analysing a synthetic general ledger and expense budget. The report compares actual expenses with budget, identifies the main drivers of variance, and provides a transaction-level review.

## View the project

- [Preview the four-page report](Zak_Aslam_General_Ledger_Review.pdf)
- [Download the Power BI file](General_Ledger_Review.pbix)

## Key findings

- Actual expenses were **£2.06M**, approximately **£150.14K (7.9%) over budget**.
- Finance had the largest departmental overspend at **£248.19K**. Marketing was the largest account-level contributor.
- Two Sales journal entries reference Bright Ads Ltd invoice **INV-10-SA-777**, each for **£2,499.99**. This is a potential duplicate that requires checking against the original invoice and any reversal.
- Operations payroll was **£39,760.61 over budget** across September and October.

## Report pages

1. **Overview:** headline figures and monthly actual expenses versus budget.
2. **Expense Drivers:** variance by department and expense account.
3. **Transaction Review:** searchable detail using month, department and supplier slicers, plus a bookmark for the potential duplicate.
4. **Key Findings:** conclusions and recommended checks.

*The dataset is synthetic. The potential duplicate is a review finding, not a confirmed accounting error.*
